# پورتفولیوی Zainab Wafi

## اجرای پروژه در VS Code
1. Node.js را نصب کن.
2. این فولدر را در VS Code باز کن.
3. در Terminal دستور `npm install` را اجرا کن.
4. دستور `npm run dev` را اجرا کن و لینک Local را باز کن.

## آنلاین‌کردن در Vercel
1. پروژه را در GitHub آپلود کن.
2. در Vercel گزینه Add New → Project را بزن و repository را Import کن.
3. Framework: Vite؛ Build Command: `npm run build`؛ Output Directory: `dist`.
4. روی Deploy کلیک کن.

لینک‌ها و متن‌ها در `src/App.jsx` هستند. عکس بخش Hero و About از فایل `src/assets/about-workspace.jpeg` استفاده می‌کند. عکس‌های پروژه از Unsplash می‌آیند و برای بارگذاری به اینترنت نیاز دارند. فرم تماس برنامه ایمیل دستگاه را با متن آماده باز می‌کند.
